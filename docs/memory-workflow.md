# روند خاطره: از گوگل‌شیت تا سایت

خاطره‌ها بدون بک‌اند و با دو دستور و یک بازبینی دستی وارد سایت می‌شوند.

## پرسش‌های پیشنهادی گوگل‌فرم

| پرسش | ستون | نکته |
|---|---|---|
| نام نمایشی | `نام نمایشی` | همان که می‌خواهند دیده شود |
| نسبت شما با او | `نسبت` | مثلاً همسایه، شاگرد |
| عنوان خاطره | `عنوان` | اختیاری |
| متن خاطره | `متن خاطره` | اجباری |
| موضوع‌ها (با ویرگول) | `موضوع` | اختیاری؛ برای جست‌وجو |
| تاریخ تقریبی | `تاریخ` | سال، سال-ماه یا روز؛ سال ۱۳۰۰ تا ۱۵۰۰ شمسی فرض می‌شود و تبدیل می‌شود |
| اجازهٔ انتشار می‌دهم (تیک اجباری) | `اجازه انتشار` | بدون «بله» منتشر نمی‌شود |
| راه تماس | `تماس` | **در سایت و فایل‌ها هرگز نمی‌آید** |
| عکس (آپلود) | `عکس` | نادیده گرفته می‌شود؛ دستی بررسی و اضافه کنید |

اگر عنوان ستون‌های فرم شما فرق دارد، فهرست `FIELDS` بالای `scripts/import-memories.mjs` را اصلاح کنید.

## گام‌ها

1. در Google Sheet: File ← Download ← CSV.
2. `npm run memories -- import <slug> فایل.csv` (برای دیدن بدون نوشتن: `--dry-run`). ردیف‌های تازه در `memories.incoming.json` می‌روند که **در git نیست**؛ پس متن بررسی‌نشده هرگز در مخزن عمومی نمی‌ماند. همه `pending` هستند.
3. فایل را بخوانید: غلط املایی، اطلاعات خصوصی (اسکریپت ایمیل/تلفن در متن را هشدار می‌دهد)، لحن.
4. `npm run memories -- publish <slug> <id> [<id>…]` خاطرهٔ تأییدشده را به `memories.json` می‌برد. اگر اجازهٔ انتشار «granted» نباشد، رد می‌کند.
5. `npm test` و سپس commit و push.

اجرای دوباره روی همان CSV تکرار نمی‌سازد (شناسه از نام و متن ساخته می‌شود).

## آنچه خودکار نیست

عکس و ویدیوی خاطره، ویرایش متن، حذف خاطره (فقط ردیف را از `memories.json` پاک کنید) و تأیید. این‌ها تا فاز بک‌اند دستی می‌مانند.
