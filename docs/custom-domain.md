# دامنهٔ اختصاصی

نشانی روی سنگ برای همیشه است؛ دامنه‌ای بگیرید که خودتان کنترلش می‌کنید.

1. دامنه بخرید؛ تمدید را خودکار کنید و ایمیل بازیابی را معتبر نگه دارید.
2. در GitHub: Settings ← Pages ← Custom domain، دامنه را بنویسید و «Enforce HTTPS» را روشن کنید.
3. در DNS: برای دامنهٔ ریشه رکوردهای A که مستندات رسمی GitHub Pages فهرست کرده، و برای `www` یک CNAME به `<username>.github.io`.
4. در مخزن: `SITE_URL` را `https://دامنه` و `BASE_PATH` را `/` بگذارید (workflow از تنظیمات مخزن می‌خواند) و دوباره deploy کنید.
5. صفحهٔ `/<slug>/qr/` را باز کنید؛ هشدار نشانی نمونه باید رفته باشد.

پس از چاپ، نشانی‌های `/g/<slug>/` و `/<slug>/` را عوض نکنید؛ یعنی `slug` ثابت بماند.
